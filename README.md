# Pong-Game
## Gameplay Overview
- This is a Pong Game for two players.
- A ball moves randomly and bounces off walls and paddles.
- Each time a player misses the ball, the oppenent scores a point
- The score is displayed on the top of the screen and updates automatically

## Features
- **Two controllabe paddles**
  - Left paddle (red): W/S
  - Right paddle (white): Up Arrow/ Down Arrow
- **Ball physics**
  - Continuous movement
  - Wall bounce
  - Paddle collision detection
- **Scoring system**
  - Scoreboard at the top
  - Auto‑reset after each point
- **Smooth animation**
  - Uses `Screen().tracer(0)` for flicker‑free rendering
- **Class‑based structure**
  - Window, paddles, ball, score, and controls are all organised cleanly
 
  ##  Controls

| Player | Move Up | Move Down |
|--------|----------|------------|
| Left Paddle | **W** | **S** |
| Right Paddle | **Up Arrow** | **Down Arrow** |
